MalScope v2.1
=============

GitHub:
https://github.com/Katiyar-crypto/MalScope

One-link Windows launch:
powershell -ExecutionPolicy Bypass -NoProfile -Command "irm https://raw.githubusercontent.com/Katiyar-crypto/MalScope/main/install_and_run.ps1 | iex"

Manual run:
1. Download https://github.com/Katiyar-crypto/MalScope/archive/refs/heads/main.zip
2. Extract it.
3. Open MalScope_v2.1.
4. Run:
   python -m pip install -r requirements.txt
   python main.py

MalScope is a PyQt6 desktop application for static malware analysis, decompilation, IOC extraction, YARA scanning, ZIP sample handling, report export, and optional AI analysis.

Use only for defensive, educational, and authorized research.
